# ฐานจันทรา: เอาชีวิตรอดบนดวงจันทร์

เกมจัดการฐานวิจัยบนดวงจันทร์ (HTML5 Canvas พิกเซลอาร์ต) เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

## โครงสร้างโฟลเดอร์

```
index.html            หน้าเว็บ + ลำดับการโหลดสคริปต์
css/
  base.css            ตัวแปรสี, reset, ปุ่ม, canvas
  hud.css             แถบสถานะ, แบนเนอร์, การ์ดลูกเรือ, กล่องคำแนะนำ
  overlays.css        เมนูเริ่ม, สอนเล่น, เลือกห้อง, หน้าจบเกม
  responsive.css      จอแคบ/มือถือ
js/
  config/             ข้อมูลคงที่ (สี, ไอคอน 8x8, ขนาดฉาก, ข้อมูลห้อง, ข้อความสั้น)
  core/               state กลาง, ตัวช่วย, update ต่อเฟรม, main loop
  graphics/           การวาดภาพนิ่ง (ฉากหลัง, ห้อง, อุปกรณ์, ทางเดิน, ไอคอน, สัญลักษณ์บนฉาก, renderer)
  animation/          สิ่งที่เคลื่อนไหว (ดาว, ฝุ่น, ลูกเรือ, จอสั่น, แฟลช, พายุ, เครื่องหมายคลิก)
  systems/            กติกาเกม (ลูกเรือ, เหตุการณ์สุ่ม, ทรัพยากร, สร้างห้อง)
  ui/                 ส่วนที่แตะ DOM (HUD, หน้าจอ, การ์ดเลือกห้อง, สอนเล่น + tutorial-art ภาพประกอบ)
  input/              รับ input (คลิก/แตะ, คีย์บอร์ด)
```

## หมายเหตุ

- สคริปต์เป็นแบบ classic script แชร์ตัวแปรร่วมกัน (global) จึงเปิดผ่าน `file://` ได้ **ลำดับ `<script>` ใน `index.html` สำคัญ** ถ้าเพิ่มไฟล์ใหม่ต้องใส่ให้อยู่หลังไฟล์ที่มันใช้
- อุปกรณ์ในห้องแต่ละชนิด (`graphics/room-props.js`) มี animation เล็กๆ ฝังอยู่ในโค้ดวาด จึงอยู่ในโฟลเดอร์ graphics

## ไอคอน

- ไอคอนทั้งหมดเป็นพิกเซล 8x8 นิยามเป็นข้อความใน `js/config/icons.js` (แก้/เพิ่มได้ในไฟล์เดียว)
- `js/graphics/icons.js` แปลงเป็นภาพให้ใช้ได้ทั้งใน HTML (`ico('wrench','md')`, หรือ `<img data-ic="wrench">`) และบน canvas (`drawIcon('wrench',x,y,3)`)
- เพิ่มห้องใหม่: เพิ่มไอคอนใน `icons.js`, ข้อมูลใน `config/rooms.js` (`ic`, `pros`, `cons`, `fx`) และฟังก์ชันวาดใน `graphics/room-props.js`
