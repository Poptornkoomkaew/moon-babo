# Moon Crisis: เอาชีวิตรอดบนดวงจันทร์

เกมบริหารจัดการฐานวิจัยบนดวงจันทร์ (Moon Base Management Simulation) พัฒนาด้วย **HTML5 Canvas** และ **Vanilla JavaScript/CSS** ในสไตล์พิกเซลอาร์ตเรโทรที่สวยงามและมีชีวิตชีวา สามารถเปิดเล่นได้ทันทีผ่านเบราว์เซอร์โดยไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์

---

## 🚀 ฟีเจอร์หลักของเกม

- **ระบบจำลองทรัพยากรแบบเรียลไทม์:** ควบคุมสมดุลของ **ออกซิเจน ($O_2$)**, **พลังงานไฟฟ้า (Power)** และ **ความแข็งแรงของตัวฐาน (Hull Integrity)**
- **ลูกเรือและระบบคำสั่งอัตโนมัติ:** ลูกเรือเดินไปมาระหว่างห้อง ขึ้นบันได และจัดการซ่อมแซมจุดเสียหายหรือเปิด-ปิดประตูแอร์ล็อค
- **เหตุการณ์สุ่มและภัยพิบัติอวกาศ:** เผชิญหน้ากับพายุสุริยะ, อุกกาบาตพุ่งชน, แผงโซลาร์เซลล์เสียหาย และความขัดข้องของห้องปฏิบัติการ
- **การขยายฐานวิจัย:** เลือกการ์ดห้องพิเศษทุกๆ 2 วันในเกม เพื่ออัปเกรดความสามารถและรับโบนัสพิเศษ
- **โหมดความยาวเกมที่หลากหลาย:** เลือกเล่นได้ 3 ระดับความยาว (3 นาที / 6 วัน, 5 นาที / 10 วัน, 8 นาที / 16 วัน)

---

## 🎮 กลไกและทรัพยากรในเกม

1. **ออกซิเจน ($O_2$):** ผลิตจากห้องควบคุม, ระบบฟอกอากาศ, และโรงเรือนไฮโดรโปนิกส์ หากรอยรั่วมากหรือระบบฟอกอากาศพัง ออกซิเจนจะลดลงจนเกมโอเวอร์
2. **พลังงาน (Power):** ได้จากแผงโซลาร์เซลล์, แบตเตอรี่สำรอง และสถานีพลังงาน ใช้ขับเคลื่อนระบบป้องกันและห้องต่างๆ หากพลังงานหมด อุปกรณ์จะหยุดทำงาน
3. **ความแข็งแรงของตัวฐาน (Hull Integrity):** ได้รับความเสียหายจากอุกกาบาตและพายุสุริยะ สามารถซ่อมแซมได้ด้วยการ์ดซ่อมบำรุงหรือให้ลูกเรือปะรอยร้าว
4. **ห้องปฏิบัติการและสิ่งปลูกสร้าง:**
   - **ฟอกอากาศ (Air Scrubber):** เพิ่มออกซิเจนเสถียร
   - **โล่ป้องกัน (Shield Generator):** ลดความเสียหายจากอุกกาบาตและพายุสุริยะ
   - **ไฮโดรโปนิกส์ (Hydroponics):** เพิ่มออกซิเจน (ระวังโรคพืชขัดข้อง)
   - **แบตเตอรี่สำรอง (Battery Bank):** เพิ่มกำลังไฟฟ้าสำรอง
   - **ซ่อมบำรุง (Workshop):** เร่งความเร็วในการซ่อมแซมและฟื้นฟูตัวฐาน
   - **พักลูกเรือ (Bunks):** เพิ่มความเร็วในการเคลื่อนที่ของลูกเรือ
   - **เรดาร์ (Radar):** แจ้งเตือนพายุสุริยะล่วงหน้านานขึ้น

---

## 🕹️ การควบคุมและวิธีเล่น

- **คลิก/แตะ:** สั่งการลูกเรือไปยังจุดต่างๆ, ซ่อมแซมรอยร้าวที่ตัวฐาน, ซ่อมแผงโซลาร์เซลล์, หรือเปิด-ปิดประตูห้อง (Airlock)
- **การ์ดห้องใหม่:** ทุกๆ 2 วันในเกม จะมีหน้าต่างเลือกการ์ดห้องใหม่เพื่อติดตั้งเพิ่มเติมในฐาน

## 🛠️ หมายเหตุทางเทคนิค

- ใช้สคริปต์แบบ Classic Script แชร์ตัวแปรผ่าน Global Scope สามารถเปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ได้โดยตรง (รองรับโปรโตคอล `file://`)
- **ลำดับการโหลดสคริปต์ใน `index.html` มีความสำคัญอย่างยิ่ง** หากเพิ่มไฟล์สคริปต์ใหม่จะต้องวางไว้หลังไฟล์ที่เป็น dependencies
- ไอคอนทั้งหมดออกแบบด้วยพิกเซลขนาด 8x8 นิยามใน `js/config/icons.js` และแปลงผลลัพธ์ผ่าน `js/graphics/icons.js` เพื่อใช้งานทั้งบน DOM และ Canvas
